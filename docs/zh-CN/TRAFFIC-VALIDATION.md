## 重启与真实 API 字段核验

- 本机采集服务停止并使用同一独立测试卷重启：历史仍在、加密密钥不变、已保存配置可读；核心和设备重连均记录缺口。
- 模拟核心未重启而采集器重启时，没有把核心已有的十余 GB 基线重复计入历史；重新连接后仅累计新观测差值。
- 对既有 RouterOS API 做过一次有界只读字段验证：基础设备记录与 `=stats=` 返回的 `.id` 全部匹配，`bytes-down`／`bytes-up` 均为数值。没有执行设备配置写入，未把真实凭据复制到测试环境。
- 这不是 NAS 上长期运行验收；生产可达性、性能和持续采集仍需在用户单独确认部署后验证。

## 交付边界

- 支持 OpenClash 总体实时／日月累计，以及 ROS 设备累计上传、下载排行。
- OpenClash 口径包含核心 DIRECT；不是机场账单，不能与 WAN 或设备总量相加。
- 不提供本期未实现的“每设备仅代理流量”归属；SNAT、分流和防火墙未改动。
- 历史从启用采集后开始，保留 365 天；首次已有计数、未知重启区间与断连缺口不伪造补算。
- 当前为本地 `preview` 构建；Portainer 正式 image-only Stack、公开镜像版本与部署操作需下一步单独确认。

构建、配置、备份及回滚步骤见 [扩展说明](../../extensions/traffic/README.md)。
